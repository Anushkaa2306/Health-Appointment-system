# Health Appointment Authentication Portal

A secure, modern patient appointment portal featuring robust authentication built with Vanilla JavaScript, HTML, CSS, and Supabase.

## Features
* **Standard Login:** Secure email and password authentication with validation.
* **Passwordless Entry:** 6-digit Email OTP verification for enhanced security and fraud prevention.
* **Social Auth:** Quick sign-in using Google OAuth.
* **Modern UI:** Clean interface with a professional medical background and password visibility toggles.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend / Auth:** Supabase
* **Email Delivery:** Custom SMTP configuration
